# Spectroscopic Data Processing with Python

Processing and analysis of spectroscopic observations from the **Nordic Optical Telescope (NOT)** to obtain calibrated and normalized stellar spectra.

## Project Overview

This project focused on the reduction and processing of astronomical spectroscopic data, from the initial organization and calibration of observational images to the extraction and calibration of one-dimensional spectra.

## Data Processing

The workflow included:

- Organization and preprocessing of observational images.
- Bias and flat-field correction.
- Extraction of the two-dimensional spectrum.
- Extraction of the one-dimensional spectrum.
- Wavelength calibration.
- Spectral normalization and linearization.
- Visualization and analysis of the processed spectrum.

## Tools and Libraries

- Python
- NumPy
- SciPy
- Matplotlib
- Astropy
- Glob

## Results

The processing pipeline was used to obtain a calibrated, normalized, and linearized one-dimensional spectrum suitable for subsequent scientific analysis.

## Academic Context

This project was developed as part of the **Master's Degree in Astronomy and Astrophysics** at the Valencian Internacional Univercity (VIU).
